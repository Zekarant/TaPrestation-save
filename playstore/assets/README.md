# Play Store Assets

Ce dossier contient les assets destinés au Play Store.

Génération automatique : utilisez `scripts/generate-icons.ps1` (Windows) ou `scripts/generate-icons.sh` (Linux/macOS). Ces scripts génèrent :
- `icon-48x48.png`, `icon-72x72.png`, `icon-96x96.png`, `icon-144x144.png`, `icon-192x192.png`, `icon-256x256.png`, `icon-384x384.png`, `icon-512x512.png`, `icon-1024x1024.png`
- `feature-1024x500.png` (Feature graphic requis par Play Console)

Conseil : ajustez la composition (padding/background) du `feature-1024x500.png` pour mieux afficher votre logo dans le Play Store.
